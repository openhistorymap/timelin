01What it is

timel.in is the OpenHistoryMap timeline, extracted into a framework-agnostic library. The core is a zero-dependency SVG renderer; thin official bindings wrap it for React and Angular, and it works anywhere ES modules do (Vite, Webpack, plain <script type="module">).

Every point in time is a decimal year — a plain number. 1492, -753 (754 BCE), 866.5 (mid-866 CE). That is what lets one axis address all of history without bumping into the edges of the JavaScript Date range.

02Install & concepts

The model is four ideas:

Yearthe cursor position, a decimal year.
Events{ id, year, endYear?, title }. With endYear they render as spans; without, as point markers. Lane-packed automatically.
Erascurated pivot points (the dashed verticals). Ships with OHM's set; override with your own.
Viewthe visible [start, end] range. Pan and zoom change it.

03Vanilla / Vite

import { Timeline } from '@openhistorymap/timeline-core';

const tl = new Timeline(document.getElementById('timeline'), {
  year: 117,
  viewSpan: 400,
  events: [
    { id: 'trajan', year: 98, endYear: 117, title: 'Reign of Trajan' },
    { id: 'vesuvius', year: 79, title: 'Eruption of Vesuvius' },
  ],
});

tl.on('yearChange', (y) => console.log('now at', y));
tl.on('eventSelect', (e) => console.log(e.title));
tl.play({ yearsPerSecond: 8 }); // ...tl.pause()

The host element just needs a height. The component injects its own stylesheet — the OHM "library at night" palette — and is fully themeable.

[(year)] is a real two-way binding; the renderer runs outside Angular's zone.

06Swimlanes (tagged groups)

Tag an event with a group and the timeline organises events into stacked, styled swimlanes with a label gutter on the left. Try the ▦ Swimlanes button in the bar above. Define groups for order, colour, and visibility, or just tag events and let the lanes be derived. 

const tl = new Timeline(host, {
  groups: [
    { id: 'politics', label: 'Politics', color: 'oklch(0.74 0.12 75)', order: 0 },
    { id: 'culture',  label: 'Culture',  color: 'oklch(0.70 0.11 210)', order: 1 },
    { id: 'science',  label: 'Science',  color: 'oklch(0.72 0.12 150)', order: 2 },
  ],
  events: [
    { id: 'rev', year: 1789, endYear: 1799, title: 'French Revolution', group: 'politics' },
    { id: 'b5',  year: 1808, title: "Beethoven's 5th", group: 'culture' },
    { id: 'volta', year: 1800, title: 'Voltaic pile', group: 'science' },
  ],
});
tl.on('groupSelect', (g) => console.log(g.id)); // gutter label clicks

Lanes auto-grow the host to fit; each group's height tracks how many of its events overlap in time (stable across zoom, capped by maxSubLanes). groupMode is 'auto' / 'swimlane' / 'flat'; groupGutter sets the label column width. Group colour tints the lane and colours its events.

07vis-timeline compatibility

Existing vis-timeline data drops straight in — array or a live DataSet, BCE included. 

import { fromVisItems, toVisItems } from '@openhistorymap/timeline-core/vis';

tl.setEvents(fromVisItems(myVisDataSet));   // vis → timel.in
const items = toVisItems(tl.getEvents());     // timel.in → vis

content→title, title→description, start→year, end→endYear, type→point/span, style→color; the original item is kept on event.data.

08Wikidata

A dependency-free adapter turns a SPARQL result into events — the path ohm.openhistoryline.org uses.

import { fetchWikidataEvents } from '@openhistorymap/timeline-core/wikidata';

const events = await fetchWikidataEvents({
  classQid: 'Q178561', // e.g. "battle"
  fromYear: -100, toYear: 500,
});
tl.setEvents(events);

09PeriodO

PeriodO is a gazetteer of scholarly definitions of historical periods — each with a temporal extent (often BCE), a spatial coverage, and a source authority. The adapter maps the dataset to events, and because periods group naturally by region or authority, straight into swimlanes. Press ⌖ PeriodO above to load the periods defined for Greece, lane-stacked by source. 

import { fetchPeriodo } from '@openhistorymap/timeline-core/periodo';

const { events, groups } = await fetchPeriodo({
  spatialCoverage: 'Greece',  // narrow the (~7.5 MB) dataset
  groupBy: 'authority',       // 'spatialCoverage' (default) | 'authority' | 'none'
});
tl.setGroups(groups);
tl.setEvents(events);

Each period becomes a span linked back to its PeriodO ARK. Have the JSON already? Use fromPeriodoDataset(dataset, opts). PeriodO years are ISO 8601 (with a year zero), so BCE years are shifted by one to match PeriodO's labels (shiftBce: false to opt out).

10Theming

Every visual is a CSS custom property, defaulted on the component root. Override per instance or globally.

new Timeline(host, {
  theme: { brass: 'oklch(0.78 0.13 40)', groundDeep: '#0c0b0a' },
});
